# Despliegue

El sitio se publica con GitHub Pages desde la rama `gh-pages`.

- El trabajo de desarrollo se hace en la rama de la tarea (ej. `claude/...`).
- Después de pushear cambios a esa rama, **fusionarlos también en `gh-pages` y pushear**
  (fast-forward merge) para que el usuario los vea en vivo sin pasos manuales.
- No hace falta pedir permiso cada vez para esto: el usuario ya confirmó que quiere
  que esto se haga siempre tras cada cambio.
